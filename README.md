# 🍷 Red Wine Quality Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![ML](https://img.shields.io/badge/ML-Classification-red.svg)

## 📖 Overview

Multi-class classification model to predict red wine quality based on physicochemical properties. Analyzes 11 features including acidity, sulfates, alcohol content, and pH levels.

## 🎯 Features

- Wine quality classification (3-8 scale)
- Physicochemical feature analysis
- Quality determinant identification
- Model comparison

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Quick Start

```bash
git clone https://github.com/adityavdn/Red-Wine-Quality.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Key Features Analyzed

- Fixed/Volatile Acidity
- Citric Acid, Residual Sugar
- Chlorides, Sulfates
- pH, Density, Alcohol
